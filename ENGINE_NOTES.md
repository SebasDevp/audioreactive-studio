# AudioReactive Studio v0.14.1 · Engine notes

## Living Systems update
- 24 modular GPU presets; each scene compiles independently.
- Dual-timescale audio envelopes plus spectral flux and spectral centroid.
- Spatial memory controls: trails, warp and echo zoom.
- Expanded waveform modes: line, double line, radial, flower, lasso and spiro.
- Tree of Life rebuilt as retracting/expanding living tendrils.
- Matrix Rain uses a dedicated clock so the global speed control can genuinely slow it down.
- Performance mode disables the expensive memory-warp post effect; HD/Ultra keep adaptive resolution available.

The engine remains Three.js/WebGL and all new visual logic is contained in this project.
